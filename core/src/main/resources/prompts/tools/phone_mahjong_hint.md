Give the best discard for the user's Sichuan mahjong (血战到底) hand on their phone. Call it only after the user has drawn, when the hand has 14 tiles counting each pon and each kan as 3: `hand` is the whole hand, `melds` the pons and kans (omit when there are none), `que` the 定缺 suit, and `advisor` the mahjong service URL on the Mac that the user gave you. Read the hand, melds and 定缺 from the user's screen with view_user_screen first. Tiles are `1m`-`9m` (万), `1p`-`9p` (筒) and `1s`-`9s` (条), e.g. `5m`; `que` is `m`, `p` or `s`. The service picks the discard with the highest expected score, so it may pass up an immediate tenpai to chase a bigger hand; follow its recommendation. The result repeats the service answer: `discard`, `target` (`fast` = quick ordinary or seven-pairs win, `qingyise` = all one suit, `pengpeng` = all triplets, `qidui` = seven pairs), `fan` (the 番 that target is worth), `value` (expected multiplier: winning chance times the multiplier, higher is better), `shanten` after the discard for that target, `ukeire` (how many tiles improve it), `waits` (which ones), `queLeft` (missing-suit tiles still in hand) and up to three `options` with the same fields; `win: true` means the hand is already complete, so tell the user they can win. An error such as `bad_tile`, `bad_que`, `bad_meld`, `not_drawn`, `wrong_count`, `too_many` or `bad_draws` comes with a `detail`: look at the screenshot again, correct the hand, melds or 定缺, and call again. `service_unavailable` means the mahjong service on the Mac is not running: tell the user. This tool never taps or changes the screen. In Chinese, tell the user which tile to discard (几万/几筒/几条), which target to chase and its expected multiplier in a phrase like 「冲清一色，期望约 1.4 倍」 (use 快胡 when the target is `fast`), then the shanten and how many and which tiles improve the hand.
