Give the best discard for the user's Sichuan mahjong (血战到底) hand on their phone. Call it only after the user has drawn, when the hand has 14 tiles counting each pon and each kan as 3: `hand` is the whole hand, `melds` the pons and kans (omit when there are none), `que` the 定缺 suit, and `advisor` the mahjong service URL on the Mac that the user gave you. Read the hand, melds and 定缺 from the user's screen with view_user_screen first. Tiles are `1m`-`9m` (万), `1p`-`9p` (筒) and `1s`-`9s` (条), e.g. `5m`; `que` is `m`, `p` or `s`. The result repeats the service answer: `discard` (the tile to throw), `shanten` after it, `ukeire` (how many tiles improve the hand), `waits` (which ones), `queLeft` (missing-suit tiles still in hand) and up to three `options`; `win: true` means the hand is already complete, so tell the user they can win. An error such as `bad_tile`, `bad_que`, `bad_meld`, `not_drawn`, `wrong_count` or `too_many` comes with a `detail`: look at the screenshot again, correct the hand, melds or 定缺, and call again. `service_unavailable` means the mahjong service on the Mac is not running: tell the user. This tool never taps or changes the screen. In Chinese, tell the user which tile to discard (几万/几筒/几条), the shanten after it, and how many tiles and which ones improve the hand.
