Mahjong hints for the user's own Sichuan mahjong (血战到底) game in JJ麻将 on their phone. When the user asks to start or turn on mahjong hints (for example 「开始麻将提示」 or 「麻将提示」), call this tool right away with `action: "watch"` and nothing else (add `advisor` only if the user gave a service URL; never ask for one, a preset service is used): it watches the user's own screen by itself, sends only frames of cn.jj.mahjong to the Mac service's /hint, and flashes one short line on Mika's floating capsule whenever it is the user's turn, when 定缺 must be chosen, and when the hand can win. The loop never calls the model and never taps or changes the screen, so do not call other tools or repeat the call while it runs. It returns `{hinted, unsure, stopped}` when it ends by itself: `stopped` is `app_left` (the user left the game for a minute, or two minutes passed without the game), `timeout` (one hour), `service_down` (the Mac service was unreachable ten frames in a row), `screen_unavailable` (screen capture stopped working), `new_message` (the user sent a new message; handle it) or `busy` (another watch is already running). The user can stop the task to end it. Tell the user once, before or after calling, that the hints will appear on the capsule while they play.

To answer once about a hand instead: give the best discard for the user's Sichuan mahjong (血战到底) hand on their phone. Call it only after the user has drawn, when the hand has 14 tiles counting each pon and each kan as 3: `hand` is the whole hand, `melds` the pons and kans (omit when there are none), `que` the 定缺 suit, and `advisor` the mahjong service URL on the Mac if the user gave one (omit it otherwise: a preset service is used; do not ask the user for it). Read the hand, melds and 定缺 from the user's screen with view_user_screen first. Tiles are `1m`-`9m` (万), `1p`-`9p` (筒) and `1s`-`9s` (条), e.g. `5m`; `que` is `m`, `p` or `s`. The service picks the discard with the highest expected score, so it may pass up an immediate tenpai to chase a bigger hand; follow its recommendation. The result repeats the service answer: `discard`, `target` (`fast` = quick ordinary or seven-pairs win, `qingyise` = all one suit, `pengpeng` = all triplets, `qidui` = seven pairs), `fan` (the 番 that target is worth), `value` (expected multiplier: winning chance times the multiplier, higher is better), `shanten` after the discard for that target, `ukeire` (how many tiles improve it), `waits` (which ones), `queLeft` (missing-suit tiles still in hand) and up to three `options` with the same fields; `win: true` means the hand is already complete, so tell the user they can win. An error such as `bad_tile`, `bad_que`, `bad_meld`, `not_drawn`, `wrong_count`, `too_many` or `bad_draws` comes with a `detail`: look at the screenshot again, correct the hand, melds or 定缺, and call again. `service_unavailable` means the mahjong service on the Mac is not running: tell the user. This tool never taps or changes the screen. In Chinese, tell the user which tile to discard (几万/几筒/几条), which target to chase and its expected multiplier in a phrase like 「冲清一色，期望约 1.4 倍」 (use 快胡 when the target is `fast`), then the shanten and how many and which tiles improve the hand.
