# JJ 斗地主适配

日期：2026-11-20（2026-11-21 修订）· 状态：电脑端认牌在做，手机端待做

## 目标

让 `phone_ddz_turn` 的 `mode=human` 在 JJ 斗地主（`cn.jj` 6.02.01）新手场里全自动打牌，复用现有的决策层（DouZero、`DdzTracker`、`HumanDdzPolicy`、`DdzSnapshotRecovery`）。

## 范围

- 只做没有实物、话费、奖金的真人场。第一版只认一个入口：**JJ 斗地主新手场**（奖励是 JJ 金币；一局是多手牌按积分排名）。
- 有奖比赛（话费券、实物、奖金）：认出来就 pause，不点。
- 工具不在大厅里导航：用户坐上牌桌或刚点完「再来一局」后接手；结算页只点白名单里的「再来一局」。
- 规则：标准 54 张，叫分（不叫 / 1 / 2 / 3）。癞子、不洗牌：pause。
- **不做加倍**：两段录屏共 10 次叫分都没出现加倍。遇到没见过的按钮组合就 pause，以后见到了再补。

## 结构（2026-11-21 改）

- 原计划把 `PhoneDdzTurn`（2707 行）抽成 `DdzSkin` 接口。实际读下来，human 模式和单机、闯关、场次页、救济金这些流程是缠在一起的；而且经典版是每 150ms 同步读一次出牌，JJ 要把截图发到电脑上认牌，节奏不同。所以改成：
  - 新写 `JjDdzTurn`，只实现 human 模式，复用决策层。**经典版代码一行不动。**
  - 对模型仍然只有 `phone_ddz_turn` 一个工具，`execute` 按前台包名分发：`cn.jj` 交给 `JjDdzTurn`。
- 分支：`flyzorro/ddz-jj`，从 `origin/main` 拉（upstream 已经同步到 0c258ac9，见 PR #175）。

## 识别

- **界面阶段和按钮**：在手机上看像素，按钮行 y≈598（2408×1080）。要同时看按钮的上下两行和宽度：沙滩皮肤下，黄色的沙子、人物、木牌会在这一行冒出假按钮。

  | 画面 | 不出 x636–876 | 提示 x1148–1392 | 出牌 x1528–1792 |
  |---|---|---|---|
  | 跟牌 | 黄 | 黄 | 绿（选的牌能出）/ 灰 |
  | 首出 | 灰 | 灰 | 绿 / 灰 |
  | 要不起 | 中间只有一个黄色按钮 x1160–1400 | | |
  | 叫分 | 不叫（粉红，约 (211,112,105)，x≈600–800）+ 1 / 2 / 3（黄可叫、灰不可叫，x≈1088–2060） | | |

  颜色：黄约 (202,166,90)，绿约 (86,181,117)，灰约 (155,157,159)。至少有两套牌桌皮肤（海景、沙滩），按钮位置一样。
- **牌**（手牌、各家出的牌、底牌）：在关键时刻把整帧 JPEG 发到电脑的 `POST /cards`（DouZero 服务，同一个 `advisor` 地址；权重路径在 `DDZ_CARDS_WEIGHTS`，没配就回 503 `cards_unavailable`）。
  返回每张牌的点数、框和置信度。哪些是手牌、哪家出的、哪些是底牌，由手机端按布局划分。
- **模型**：torchvision Faster R-CNN + MobileNetV3（BSD-3），代码在 `tools/cardvision`。YOLOX 的 PyPI 包锁死 onnxruntime 1.8，Python 3.14 装不上，所以放弃；Ultralytics 是 AGPL，不用。
- **数据**：`prelabel.py` 先找墨迹块，按外形聚类，人工给每一类起名（rec1 起了 31 类，之后的录屏按这 31 类自动命名），再用竖排的「J O K 大/小」认出王。
  截图、标注、权重都不进仓库，放在 `~/data/cardvision/`。
- **兜底**：不再用模板兜底。连不上电脑 → `service_unavailable`；置信度低，或者认出的张数和手牌张数对不上 → `low_confidence`，pause。

## 安全

- 每次点击前随机等 1.5–4 秒（在 15 秒倒计时内）；每次调用受 `hands` 限制（默认最多 10 手）。这只能降低封号风险，不能消除（APK 里带 `libmsaoaidsec.so`、`libfacedevice.so`）。
- 弹窗白名单：只点标定时见过的 ✕ 和「再来一局」。遇到充值、购买、开通、看视频、报名或没见过的弹窗，一律 pause。

## 录屏观察

- 屏幕是 2412×1080，scrcpy 录出来是 2408 宽。录屏如果从竖屏的大厅开始，抽帧时要跳过竖屏那一段，否则横屏画面会被压成竖屏尺寸。
- 一局 = 多手牌：每手结束是本手结算浮层（±分、各家剩下的牌）→ 晋级路线页 → 段位徽章过场 → 新牌桌。终局页有排名、JJ 金币奖励，以及「返回」「再来一局」两个按钮。
- 对手旁边的翻页牌显示**剩余张数**；顶栏有三张底牌（动画时会被压暗、偏蓝）、`排名/人数` 和 `底分x倍数`。
- 刚出的牌泛暖黄色，炸弹和火箭有全屏动画；选中的牌上移约 35 像素。
- 叫分时三家用 3D 角色，出牌时换成农民和地主的形象。

## 验收

1. 认牌：在留出的帧上，有牌的帧点数全对比例 ≥ 99%（要先人工修正预标注），每种点数都有验证样本。
2. 界面阶段：录屏里的叫分、首出、跟牌、要不起、本手结算、晋级页、终局页都有截图测试；经典版测试全部通过。
3. 实战：新手场连续自动打 10 手，没有误点，没有 `hand_drift`；pause 只能来自白名单以外的画面。
