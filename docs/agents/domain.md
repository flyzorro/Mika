# Domain Docs

This repository uses a single-context domain documentation layout.

## Before exploring

Read these files when they exist:

- `GLOSSARY.md` at the repository root.
- `docs/adr/` for architecture decision records relevant to the area being changed.

If these files do not exist, proceed without creating them automatically.

## Vocabulary

Use terminology defined in `GLOSSARY.md` when it exists. If a domain term is missing, treat that as a possible gap for a future domain-modeling task.

## ADR conflicts

If a proposed change conflicts with an existing ADR, call out the conflict explicitly instead of silently overriding it.
